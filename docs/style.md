# Style

The name is **Scrapbench**: one word, capital S only. Never ScrapBench, never SB.

Vocabulary, in UI text, docs and type names:

- *scrap*: one fragment of text between two separators.
- *bench*: the panel.
- *transformer* (or *tool*): an action on selected text.

Do not call the product or its scraps "notes" or a "journal".

Voice in UI copy, errors, README and release notes: short sentences, no exclamation
marks, say what happens and what does not.

Visuals: monospace everywhere in the app; emphasis is colour or weight only. One accent,
amber: `#E0A030` in dark mode and on the icon, `#C98A1E` in light mode. Icon: two lines,
one short line and an amber caret; sources in `Resources/Icon/`. Nothing that looks
commercial: no pricing, no "Pro", no waitlists.

Author name, `sergey@nosenko.org` and the GitHub handle are spelled the same in README,
About, CODEOWNERS and SECURITY.md.
