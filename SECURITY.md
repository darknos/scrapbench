# Security

Scrapbench runs locally and talks to no network service. It reads and writes
one text file you choose, plus backups and rescue copies under
`~/Library/Application Support/Scrapbench/`.

## Reporting a vulnerability

Send a report to Sergey Nosenko at `sergey@nosenko.org`. Do not open a public
issue for a vulnerability. You get a reply within 7 days. Fixed issues are
described in the release notes once the fix ships.

## Supported versions

The latest tagged release gets fixes. Older releases do not.
